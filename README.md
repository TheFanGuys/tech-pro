# Tech Pro

HVLS fan and VFD field-service tool. Pick a fan brand and model to get drive parameters, diagnostics, reference info and technician tools.

**Open it:** https://thefanguys.github.io/tech-pro/

Nothing you enter is stored in this repo.

Single-file app (index.html), no build step. Hosted on GitHub Pages. Upload a new index.html to update it.
